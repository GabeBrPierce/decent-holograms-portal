Decent Holograms Portal (Unofficial)

    Pick something to edit

    Choose a hologram or display on the left, or create a new one. Changes go live in game as soon as you save.

    Holograms are the classic multi-line kind with pages and click actions. Displays are single text, item or block display entities with scale, rotation, background color and lighting. Animations are your own text animations, used in any line with <#ANIM:name>text</#ANIM>.
